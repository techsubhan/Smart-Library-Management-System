# Smart Library Management System

This is a simple C++ project made for practicing Data Structures and Algorithms.

The project helps manage library books using different data structures.

## Features

- Add and delete books
- Search books by ID and title
- Display all books
- Issue and return books
- Manage book reservations
- Search books using AVL Tree
- DFS and BFS traversals

## Data Structures Used

- Singly Linked List
- AVL Tree
- Circular Queue

## Language

- C++

## How to Run

Compile the program:

```bash
g++ -std=c++17 library.cpp -o library
```

Run the program:

```bash
./library
```
